# Vaibhav.dev | Developer Portfolio 🦇🕸️

A responsive, dual-themed personal portfolio showcasing my journey as a 1st-year Computer Science and Business Systems (CSBS) student, aspiring Software Development Engineer, and embedded electronics enthusiast.

Live Demo: [Insert your GitHub Pages link here]

## ✨ Key Features

* **Dual-Identity Theming:** A seamless `localStorage`-saved theme switcher.
  * **Dark Mode (Gotham OS):** Deep midnight carbon, tactical amber Batsignal accents, and a custom CSS-animated hanging Batman.
  * **Light Mode (Queens Web-Slinger):** Clean comic-paper white, Ditko-red and Cobalt-blue accents, complete with an authentic vintage Ben-Day dot matrix background and an upside-down Spider-Man.
* **Interactive Physics:** Features a custom CSS pendulum swing and a JavaScript-triggered bungee-bounce effect on the hanging heroes.
* **Smooth Scrolling & Navigation:** Utilizes `IntersectionObserver` for performant scroll-reveal animations and active-link highlighting.
* **Mobile-First Design:** Fully responsive layout with a custom slide-out hamburger menu and backdrop blur.

## 🛠️ Tech Stack

Built focusing on core web fundamentals without heavy frameworks:
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Custom variables, grid/flexbox layouts, glassmorphism, and hardware-accelerated animations.
* **Vanilla JavaScript (ES6+):** DOM manipulation, Intersection Observers, and event handling.
